# FranLumi 多课本与双空间设计

## 入口与导航

正式入口为 `index.html` → `src/site.jsx` → `src/grammar-preview/main.jsx`。单词空间按需加载 `src/textbooks-preview.jsx`；两个空间共享账号、备份和设置，分别保存最后访问页。

单词导航：首页、课本过关、每日检测、易错复习、学习记录。语法导航：首页、课本语法、时态专题、练习复习、学习记录。头像菜单提供切换账号、设置和退出；手机底栏和顶栏固定，正文在中间滚动。

`textbooks-preview.html` 和 `franlumi-preview.html` 使用隔离预览数据，不读取正式账号的云端记录。内置词库与正式版共用，用户导入的词库和备份不会作为网页资源发布。

## 课本、词库与检测

每本课本使用稳定 ID，保存独立主进度、复习记录、错题本和题目检测。内置 B1、Inspire A1、A2、A1 词库不可被备份替换；自定义词库经过字段、ID、词数和大小校验后加入书架。

课本过关以 Part 为单位，每组对应完整主题。翻词、自评、助记与手动错题标记分别操作；本轮重复判定不重复计数，改选替换原判定，新轮可累计。已过关集合不因重测错误而撤销。每日检测只抽取本书已过关内容，不推进主进度。

易错复习的“错题本”仅包含手动加入的词；取消标记进入“已巩固”，任何页面取消都生效，重新加入则撤销巩固。不会根据连续答对或错误率自动移出。

课本、每日与错题复习统一提供“翻译 / 题目”切换。题目检测支持选择和判断；课本范围为当前主题、每日范围为当前组、错题范围为当前 Part。重新检测或切换组后滚动到首词。菜单打开定位当前选项，选项顺序保持教材顺序，正文不随菜单跳动。

## 持久化、备份与账号

游客和每个账号使用独立缓存，原存储键与已迁移账号 ID 保持兼容。退出恢复游客空间；切换失败保留原账号。启动先展示本机记录，再通过 Supabase 验证会话、核对云端版本。

账号与游客记录分别保存；自动同步使用 ETag 条件写入，冲突时保留本机记录，并在设置中处理。

完整备份包括书架、主进度、副进度、题目检测与成长记录、语法与时态记录。恢复前验证并确认；非法数据不修改现有状态。旧记录只读迁移，原缓存保留。

## 成长统计

新掌握需至少三个不同轮次，最近五次判定错误率严格低于 30%，且最近一次答对。达标后的正确复习按词和日期去重，复习不会增加新增掌握。每日、每周、每月和累计展示同一份长期账本。

题目明细保存最近 50 轮，成长记录随完整备份和账号记录保存。旧数据只使用仍可验证的日期和轮次。

## 托管与 Android

页面、PWA 和 API Worker 只部署到 Cloudflare，认证、数据库和头像由 Supabase 提供，详见 [部署说明](CLOUDFLARE.md)。Android 加载 APK 内置资源，缺失资源不请求远程旧站；API 和认证仅连接配置的 HTTPS 主机。

Android 包名、签名、本地 WebView 来源、学习存储键及旧更新器下载文件名属于升级兼容约定，不代表另一个线上项目。保留这些约定可继续覆盖安装并读取已有记录。

## 验证

`test:study`、`test:navigation`、`test:choices` 验证检测与交互；`test:account`、`test:profile`、`test:production`、`test:startup` 验证账号与本机记录；`test:release` 验证发布白名单。`test:cloudflare`、`test:pwa`、`test:android` 分别覆盖当前后台、离线应用和原生更新约定。

发布前构建网站与 Android 网页资源，检查最终文件白名单；实际邮箱、跨设备同步和真机安装需分别验收。
